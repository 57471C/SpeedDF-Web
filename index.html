Our Commitment to Privacy

speedDF is built on a privacy-first, local-only architecture. We believe your data belongs to you, and we have designed the application to ensure your files and activity remain private.

1. Zero Data Collection

We do not collect, store, or transmit any user data, personal information, or document contents. When you view, annotate, reorganize, or edit PDFs using speedDF, all file processing happens exclusively on your local machine. No file bytes or metadata are ever uploaded to our servers or any third-party services.

2. Network Activity

The application only initiates network requests in the following scenarios:

  • Update Checks: The app may periodically query public API endpoints (like GitHub releases) or our official website to determine if a newer version of speedDF is available.
  • Support Inquiry Form (Opt-in): If you choose to manually submit support requests via this website, the email and description details you input will be received by us to help resolve your request.

3. Third-Party Links

Our website contains links to external platforms such as GitHub and Buy Me a Coffee. These third-party sites have their own privacy policies, and we do not assume responsibility for their practices.
